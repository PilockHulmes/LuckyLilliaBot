## CyberPi 使用版本

当前赛博皮使用 **legacy** 组合：

- LuckyLilliaBot：**7.12.14**（tag `v7.12.14`）
- LuckyLillia Desktop：**2.7.2**
- PMHQ：**7.1.1**
- QQ：**6.9.86-42941**

`main` 的 8.x 使用 Direct 模式，需要 Auth Token；legacy 使用 PMHQ + 本地 QQ，不需要 token。  
旧的 macOS CLI 构建流程在 tag `v7.12.14` 中会下载 `QQ-macos.zip` 并放入 `bin/qq`；当前 `main` 不再包含这个步骤。
